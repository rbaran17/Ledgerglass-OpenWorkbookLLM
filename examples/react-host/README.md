# React host example

A product page that embeds the Ledgerglass editor the way an application would: a toolbar with the workbook name, the current revision, Download XLSX, Open file (XLSX or CSV) and Reset, above a sized container that holds `<AuditWorkbook />`. The assistant panel asks this page's own server (`/api/propose`) for a proposal. The server does not call a model: it adds up the typed numbers in one column of the approved selection and proposes the sum in the empty cell below them.

Build and run it from the repository root (the package resolves to the built `lib/` of this repository, so run `npm ci && npm run build:lib` first):

```sh
node examples/react-host/build.mjs && node examples/react-host/server.mjs
```

Then open http://127.0.0.1:4310/ (set `PORT` to change the port). The server listens on 127.0.0.1 only.

Check it with a headless browser:

```sh
CHROME_PATH=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome node examples/react-host/verify.mjs
```

Leave `CHROME_PATH` out to use the browser Playwright installed. `verify.mjs` builds, starts the server on a free port and prints one `PASS` line per check.

## Files

- `src/main.jsx`: the entry point. It imports the library stylesheet (`@ledgerglass/workbook/style.css`) and mounts `App`.
- `src/App.jsx`: the page. It creates the starting workbook (a small budget with a SUM), mounts `AuditWorkbook` with `createHttpAdapter({ endpoint: "/api/propose" })`, and implements the toolbar with `exportWorkbookToXlsx`, `importWorkbookFile`, `importDelimitedFile`. Changing the workbook's `id` is how Reset and Open file switch documents.
- `src/app.css`: the page layout. `#root` and the editor container need a definite height; without it the grid sizes itself from its row count and the page stops responding.
- `server.mjs`: a Node HTTP server with no framework. It serves `public/` and answers `POST /api/propose` with a proposal checked by `validateAssistantProposal` from `@ledgerglass/workbook/node`. The comment in `proposeSum` marks where a real model call would go; authenticate the user there, too.
- `build.mjs`: bundles `src/main.jsx` with esbuild into `public/assets/` and writes `public/index.html`, with the content security policy the page is served with.
- `verify.mjs`: builds, starts the server, drives the page in Chromium and checks the grid, the SUM, the revision, the download (read back with `readWorkbookFile`), opening XLSX and CSV files, the assistant endpoint and Reset.
- `public/`: generated by `build.mjs` and ignored by `.gitignore`.

## Content security policy

The page sets its own policy in `build.mjs`. The one requirement from the library is `worker-src blob:`: the editor's parser and calculation workers start from blob URLs. A host whose policy does not allow them will see the editor fail to start.
